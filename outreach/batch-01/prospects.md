# Batch 01 — Prospect Intake
## Invulinstructie (2 min per merk)

**Bron:** Meta Ad Library → zoek op niche + NL → filter "Active ads" → kijk naar video-ads.
**Kijk op:** hoeveel ads actief (≥3 = budget aanwezig), hoe ziet de opening van hun video eruit (hook?), welk product staat centraal.
**Vul in:** alleen wat je ziet. Geen gokken. Laat velden leeg als je het niet weet.

Nadat je alle 10 slots hebt ingevuld:

```
node outreach/gen-outreach.js
```

Dat genereert per ingevuld merk een volledig Loom-script + mail + tracker-rij.
