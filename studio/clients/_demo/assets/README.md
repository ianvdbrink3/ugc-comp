# Demo-assets (placeholders)

Dit zijn lege placeholder-bestanden (0 byte) die alleen de **naamconventie** en de
werking van `delivery.js` demonstreren. Er zit geen echte video in.

Conventie: `V<nr>_<type>_<lengte>_<hook>.mp4` — bv. `V01_cold_15s_minder-is-meer.mp4`.
`delivery.js` leest alleen media-extensies (.mp4/.mov/.webm/.m4v) en negeert dit bestand.
