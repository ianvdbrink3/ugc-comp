# 05 — Livestream-knipsels & hooks (TikTok Shop Live)

*TikTok Shop draait deels op livestreams. Deze prompt levert (a) korte hooks/segmenten om live te gebruiken en (b) knipsels die je ná de live als losse shoppable video's hergebruikt.*

```
Genereer livestream-materiaal voor [PRODUCT] op TikTok Shop NL met persona/host-stijl
"[LABEL]". Twee delen:

DEEL A — LIVE-SEGMENTEN (script om live te gebruiken):
Lever 5 herhaalbare segmenten van 30–60 sec die een host elke live kan inzetten:
  1. Opener / scroll-stop voor wie net binnenkomt ("je komt precies op tijd, want ...")
  2. Productdemo met één duidelijk voordeel + Shop-CTA ("getipt product, tik onderaan")
  3. Objectie wegnemen (de meest gestelde twijfel, onderbouwd beantwoorden)
  4. Sociale bewijskracht (alleen aangeleverde, onderbouwde reviews/cijfers)
  5. Urgentie-segment gekoppeld aan het 2%-venster / live-only voordeel (alleen als waar)

DEEL B — KNIPSELS VOOR HERGEBRUIK (na de live):
Beschrijf hoe je 3 momenten uit de live knipt tot losse 15s shoppable video's:
  - welk moment, waarom het scroll-stopt, welke tekst-overlay erbij
  - 9:16 bijsnijden, safe zones respecteren, AIGC-label

REGELS: alleen onderbouwde claims, geen verzonnen aantallen, geen verboden
gezondheidsclaims, geen valse schaarste. Maak reclame herkenbaar. Als de host
AI-gegenereerd is: AIGC-label en zichtbare AI-vermelding (EU AI Act Art. 50).
```
